# RESQOS

## AI-Powered Emergency Decision Support & Response Coordination System

RESQOS is an AI-powered decision-support system for heavy-rain
preparedness in high-risk river and mountain regions of Uttarakhand.

The system combines real-time weather and geospatial data to assess
risk, identify emergency resources, and generate location-specific
preparedness plans.

## Semester 1

- Heavy-rain monitoring
- Geospatial risk assessment
- Emergency resource identification
- AI-generated preparedness plans
- Emergency command dashboard
